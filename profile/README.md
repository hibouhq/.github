# Hibou

**Eyes on what you ship.** Hibou is self-hosted, open-source security intelligence for the software lifecycle. Bring dependency vulnerabilities, code findings, secrets, coverage, and release impact into one workspace on your own infrastructure.

[Get started](https://github.com/hibouhq/hibou) · [Documentation](https://hibouhq.github.io/hibou/latest/getting-started/introduction/) · [Releases](https://github.com/hibouhq/hibou/releases) · [Discussions](https://github.com/hibouhq/hibou/discussions)

Hibou is currently in alpha and is self-hosted only; it is not a hosted SaaS offering.

## Projects

- [Hibou](https://github.com/hibouhq/hibou) — the security intelligence platform.
- [Hibou IDE extensions](https://github.com/hibouhq/hibou-ide) — bring Hibou findings into VS Code and JetBrains IDEs.
- [Sample project](https://github.com/hibouhq/hibou-sample-project) — an intentionally vulnerable project for trying out Hibou.

For questions, visit [Discussions](https://github.com/hibouhq/hibou/discussions).
